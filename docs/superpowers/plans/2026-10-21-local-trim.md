# 本地运行与功能裁剪实施计划

**Goal:** 在本机运行裁剪后的物业系统并交付可重复启动的方法。

**Architecture:** 统一功能开关用于入口和请求过滤；后端共享代码保留。独立本地配置、启动脚本和运行数据目录隔离原演示环境。

**Tech Stack:** Express、Vue 2、uni-app、Java 8、Maven、Spring Boot 2、MySQL、Redis、Kafka。

- [ ] 运行环境与依赖：检查工具、端口和本地数据库；下载项目专用 Java/Maven；实际编译并记录失败原因。
- [ ] Web 裁剪：添加统一的停用功能策略；过滤新旧缓存菜单；拒绝停用页面和接口；代理默认使用 127.0.0.1:8012。用 Node 测试真实 HTTP 响应及保留收费、公众号入口。
- [ ] 移动端裁剪：移除停用首页和个人中心入口，阻止旧路由访问；保留缴费、资产、账户和服务号相关能力。
- [ ] 后端本地配置：设置数据库、Redis、注册中心及消息队列的本地地址；添加停用任务和接口规则；不执行远程业务调用。
- [ ] 数据与运行：使用单独本地数据目录导入随附 SQL；按依赖顺序启动中间件和 Java 服务；验证登录、菜单、业主和费用查询。
- [ ] 交付：补全启动/停止脚本、运行说明和实际验证结果；若外部依赖无法取得，记录精确阻塞点和已验证的可用范围。
